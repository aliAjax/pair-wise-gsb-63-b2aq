# 游乐设施日常检验与缺陷闭环平台

基于 Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket 和 Vite 的独立前端工程。数据默认保存在 localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- 新建检验任务，逐项录入磨损、异响、制动、锁止和安全装置结果。
- 缺陷处置泳道、风险排序、责任人调整和资源冲突提示。
- 状态流转校验、停用隔离、复测与闭环审计。
- JSON 记录导出、版本号和完整操作时间线。

## 断网并单与闭环联动（值班室 ↔ 平板）

- **断网留平板/值班室**：总览可切换「断网/在线」与「补传故障」；断网期间平板的座舱锁扣、制动油温等录入和值班室对同张设备单的改动都进入本地离线队列，不互相覆盖。
- **回连并单**：同设备 + 同班次的记录按记录时刻并单；每个检验项保留各来源版本，冲突值两版并存，有效值取记录时刻最新一版（`src/services/sync.ts`）。
- **无争议值原则**：整改责任人、停用判断只采用没有争议的值——整改人两版不一致时置空待值班主管裁定；停用判断有争议时按未停用处理并禁止停用设备进入复测。
- **补传重试 / 幂等**：补传失败只重试未完成项，失败原因留痕；每条离线操作带幂等键，重复回连不重复入库、不追加审计。
- **结果改动联动**：结果变化后未执行的复测单自动作废（已完成复测保留）；放行审批按新值重新判定；已办结批次保留原办结依据快照、并列复审项后转「需复核」。
- **有效批次同一口径**：看板、详情、审计都只展示 `有效` 批次；旧记录缺班次标识先 `待核`，值班主管核实班次后才进入看板、泳道与审计时间线。
- 演示数据中含一条缺班次的旧批次（碰碰车）和一条已放行办结批次（摩天轮），可直接在详情页用「一键」按钮复现早班平板锁扣 vs 晚班值班室油温的完整冲突场景。

## 启动

```bash
npm install
npm run dev
```

访问 `http://localhost:18463`。

## 构建与规则验证

```bash
npm run build   # 类型检查 + 生产构建
npm run verify  # 运行断网并单/冲突/复测/放行/办结/幂等等 29 项场景断言
```
